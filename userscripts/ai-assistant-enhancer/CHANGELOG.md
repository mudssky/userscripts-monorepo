# ai-assistant-enhancer

## 0.1.4

### Patch Changes

- 支持豆包「快速 / 专家 / 办公任务」模式顺序设置，默认按「专家 / 办公任务 / 快速」尝试可用模式。

## 0.1.3

### Patch Changes

- 修复 Preact 入口加载 React 图标组件导致配置面板挂载失败的问题。
- 新增「开始检查延迟」配置，刷新页面或点击「新对话」后等待页面稳定再检查，减少过早回退到「思考」的情况。

## 0.1.2

### Patch Changes

- 修复刷新页面和点击「新对话」后自动切换可能早于豆包重置默认模型执行的问题；自动触发会在短时间窗口内复查，确保回到「快速」后仍能切到「专家」。

## 0.1.1

### Patch Changes

- 修复手动切换「快速」会被自动切回的问题；自动切换仅在页面初始化、路由变化和点击「新对话」时触发。
- 保留「立即检查」作为显式手动执行入口。

## 0.1.0

### Minor Changes

- 新增 AI 助手增强油猴脚本，首版支持豆包自动优先切换「专家」，不可用时回退「思考」。
