# AI 助手增强器

AI 助手体验增强油猴脚本。当前支持豆包，进入聊天页或点击新对话后，按用户设置的优先级自动选择「专家 / 办公任务 / 快速」等模式。

## 功能

- 默认启用豆包模式优化。
- 油猴菜单可切换脚本总开关。
- 页面右侧提供收起式配置面板。
- 配置持久化到油猴存储。
- 可自定义豆包模式优先级，默认顺序为「专家 / 办公任务 / 快速」。
- 可配置模式切换确认延迟，避免模式回写较慢时过早尝试下一项。
- 面板显示最近一次切换状态，便于排查页面 DOM 变化。

## 开发

```powershell
pnpm --filter ai-assistant-enhancer dev
pnpm --filter ai-assistant-enhancer build
pnpm --filter ai-assistant-enhancer qa
```

## 验证

1. 打开 `https://www.doubao.com/chat`。
2. 确认脚本开启时，模式会按设置顺序自动切到可用模式。
3. 在设置面板调整模式优先级，刷新页面后应保持上一次顺序。
4. 登录态点击「专家」后，应在确认延迟窗口内保持为「专家」。
5. 通过油猴菜单关闭脚本后，不再自动切换。
